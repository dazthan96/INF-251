# INF-251 · Programación en Dispositivos Móviles II

Este repositorio contiene los avances realizados en la materia **INF-251: Programación en Dispositivos Móviles II**, incluyendo:

- 📚 Tareas desarrolladas durante las clases
- 🧪 Ejercicios prácticos y proyectos guiados
- 🚀 Avances personales y exploraciones fuera del aula

## 📦 Estructura del repositorio

Cada subcarpeta representa una parte del avance de materia y dentro contiene los proyectos de Android Studio, uno por cada avance.
Estos proyectos pueden incluir actividades, fragmentos, navegación, persistencia de datos, y otras funcionalidades propias del desarrollo móvil en Android.
Es posible que existan algunos errores, o formas mas efectivas de hacer un trabajo, no tomes este repositorio como una guia de aprendizaje, es un diario de avance personal
